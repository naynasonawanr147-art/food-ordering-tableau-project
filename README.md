# Food Ordering Behaviour and Consumer Trends

## Problem
Food delivery is highly competitive. Businesses have large amounts of data but struggle to see what drives order demand and delivery performance.

## Dataset
About 50,000 food orders across 6 cities (Mumbai, Pune, Bangalore, Delhi, Chandigarh, Hyderabad), with fields such as Order Id, Order Value, Delivery Fee, Cuisine, Meal Type, City and Time Taken To Order.

## Tools
Tableau Public

## Steps
1. Downloaded the dataset and loaded it into Tableau
2. Checked the columns and data types
3. Built four charts: Orders by City, Cuisine Popularity, Orders by Meal Type, Delivery Time Distribution
4. Combined them into an interactive dashboard with filters
5. Created a Tableau Story with 6 scenes
6. Published to Tableau Public

## Key Insights
- Mumbai has the most orders, but demand is spread evenly across all cities
- Desserts is the most ordered cuisine, with only a small gap to the others
